# WORDWISE – English–Thai Vocabulary Quiz

เว็บแบบทดสอบคำศัพท์ 520 คำ (รายการ 1–520 ตามภาพที่ผู้ใช้ส่ง)

## ความสามารถ
- คลังคำศัพท์ 520 รายการ พร้อมคำแปลไทยและชนิดคำ
- เลือกจำนวนข้อสอบ 20, 50, 100, 300 หรือทั้งหมด 520 ข้อ
- สุ่มคำถามใหม่ทุกครั้งที่กดข้อต่อไป โดยไม่ซ้ำกันภายในรอบ
- อังกฤษ → ไทย และไทย → อังกฤษ
- ฟังเสียงอ่านคำศัพท์ภาษาอังกฤษด้วยเสียงสังเคราะห์ของเบราว์เซอร์
- เฉลยทันที พร้อมคะแนนและแถบความคืบหน้า
